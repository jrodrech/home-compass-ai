# Home Compass AI

## Problem

Home search today is largely filter-based and does not capture personal needs and constraints.

## Target User

This project is designed for a buyer seeking personalized home recommendations.

## Phase 1 Goal

The initial goal is to rank a curated set of properties based on a user's preferences and provide transparent explanations for those rankings.

## Phase 1 Out of Scope

The following are out of scope for Phase 1:

- ML models
- LLMs
- Automatic web scraping
- External APIs
